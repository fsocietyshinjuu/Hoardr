Everything in one place

Built around the way you actually use it: subscribe, forget, browse.

🔑 In-app login

Sign in inside Hoardr. It closes itself the moment you're logged in, and shows a ✓ for every site you're signed in to. No cookie exporting.

📚 Subscriptions

Add a profile once. Each check downloads only what's new, so nothing is fetched twice.

📊 Live progress NEW

A progress bar, new-file counter and current filename, with the gallery filling up as files arrive.

👀 Streaming preview NEW

Thumbnails appear one by one as they're found, with a Stop button. Check a profile before you subscribe.

🖼️ Built-in gallery

Browse each profile's photos and videos in the app, one click to open.

⏱️ Auto-check

Every 30 minutes up to daily, so your library stays current on its own.

🔄 Auto-update

New releases download in the background, then one click to restart and update.

📦 Nothing to install

The download engines (gallery-dl and yt-dlp) are bundled in every build.

How it works

Log in

Click 🔑, pick a site and sign in. The window closes by itself.

Preview & add

Paste a profile link, press Preview, then Add.

Relax

Hoardr downloads, shows progress and keeps it updated.

Changelog

What's new in each release. All releases ↗

v1.1.02026-11-18

  • New app icon for the app, installers and window.
  • Live progress: progress bar, new-file counter and current file while syncing, with the gallery updating as files arrive.
  • Streaming preview: thumbnails appear as they are found, with a Stop button and a clear error if nothing is found.
  • Smarter login: Hoardr detects a successful login, saves the session, closes the popup and shows a ✓ per site.
  • Fixed: logins now persist after the popup closes and across restarts.
  • Refreshed landing page.

v1.0.02026-11-18

  • First release: in-app login, subscriptions, auto-check, preview, gallery and auto-update.
  • Windows, macOS and Linux builds with gallery-dl and yt-dlp bundled.
