## Hoardr 1.1.0

MediaGrab is now **Hoardr**, and it can show you a profile before you download it.

### What's new
- 👀 **Profile preview**: paste a URL, press Preview (or Enter) and get the profile name plus a thumbnail grid of the first 24 items. Nothing is saved until you click Download.
- 🏷️ Renamed to Hoardr (new installer names and app ID).

### Downloads
| Platform | File |
|---|---|
| Windows | `.exe` installer or portable |
| macOS | `.dmg` (unsigned: right-click → Open on first launch) |
| Linux | `.AppImage` / `.deb` |

### Notes
- Some sites don't expose thumbnails or block hotlinking; those items show a 🖼️/🎬 placeholder.
- Private profiles may need a cookies file from your own logged-in account.
- Paid/subscriber-only platforms remain blocked.

See [CHANGELOG.md](CHANGELOG.md) for details.
