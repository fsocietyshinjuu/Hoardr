## Hoardr 1.2.0

### What's new
- 🌐 **Use login from your browser**: choose Brave, Chrome, Firefox, Edge and others under *Advanced*. Hoardr reuses that browser's existing login, which fixes "Nothing found" on sites such as X that require sign-in.
- 🔗 **Open in browser**: view the profile URL in your default browser.
- 🩺 Clearer preview errors.

### Downloads
| Platform | File |
|---|---|
| Windows | `Hoardr-Setup` installer or `Hoardr-Portable` |
| macOS | `.dmg` (unsigned: right-click → Open on first launch) |
| Linux | `.AppImage` / `.deb` |

### Notes
- Newer Chromium-based browsers (Chrome, Brave, Edge) can block cookie reading on Windows. If it fails, try Firefox or a cookies file.
- Paid/subscriber-only platforms remain blocked.
