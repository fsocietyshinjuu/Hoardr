## Hoardr 2.0.0: now a subscription app

Hoardr now works like a profile manager: log in once, subscribe to profiles, and let it keep them synced.

### What's new
- 🔑 **Log in inside the app** to Instagram, X, Facebook, Threads, TikTok, Reddit, Pinterest, YouTube or any site. No browser cookie hacks.
- 📚 **Subscriptions** with incremental downloads (only new posts).
- ⏱️ **Auto-check** schedule.
- 🖼️ **Gallery** per profile.

### Downloads
| Platform | File |
|---|---|
| Windows | `Hoardr-Setup` installer or `Hoardr-Portable` |
| macOS | `.dmg` (unsigned: right-click → Open on first launch) |
| Linux | `.AppImage` / `.deb` |

### Notes
- If a site blocks login inside the app window (some "Sign in with Google" flows do), use that site's email/password login.
- Heavy use of a logged-in account can trigger a site's rate limits. Use a longer auto-check interval.
- Paid/subscriber-only platforms remain blocked.
